# TrainWatch · frontend

Angular 22 (standalone y con signals), creado con `npx @angular/cli@22.3.0 new`. Pruebas con Vitest, que trae la plantilla.

```bash
npm ci                       # instala las dependencias exactas del package-lock.json
npm start                    # servidor de desarrollo en http://localhost:4200
npx ng test --watch=false    # pruebas una vez (sin --watch=false se quedan vigilando)
npm run build                # compila en dist/frontend
```

De momento solo hay una página «en construcción». El mapa llega en la fase 5 (ver `docs/PLAN.md`).
